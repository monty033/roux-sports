## The defect this fixes

The feed sends a full goal event for every goal and the app throws all of it away. `LandingGoalDto` keeps only `isHome`
and `teamAbbrev`, and `LandingAdapter` walks the goals solely to count them into `PeriodScoring`. So the page can say
"2–1 in the first" but cannot name a scorer, a strength, or a season total, even though each goal carries all of it.

Verified in `data/src/test/resources/fx/2026-10-26/gc-final-landing.json`, goal keys include: `playerId`, `name`
(`{"default": "..."}`), `firstName`, `lastName`, `timeInPeriod` (`"10:58"`), `strength` (`ev` / `pp` / `sh`),
`goalModifier` (`none`, plus empty-net and penalty-shot variants), `goalsToDate`, `awayScore`, `homeScore`, `isHome`,
`assists[]` of `{name, assistsToDate, playerId, sweaterNumber}`.

**`goalsToDate` is the season total as of that goal** — use it, never look the player up, and never count goals in the
payload to derive it. **The running score is in the payload** (`awayScore`/`homeScore` after the goal) — never replay
goals to compute it.

## Required work

**A. Keep the goal detail.**

- Extend `LandingGoalDto` with the fields above, defensively: every new field nullable, `name` and assist `name` as the
  existing `LocalizedNameDto`, `assists` as `List<LandingGoalAssistDto?>?`.
- Add to `:domain` (framework-free, in `GameDetail.kt` beside `PeriodScoring`):

  ```kotlin
  enum class GoalStrength { EvenStrength, PowerPlay, ShortHanded, Unknown }   // unknown keeps the goal, not the label
  enum class GoalModifier { None, EmptyNet, PenaltyShot, Other }

  data class GoalAssist(val name: String, val assistsToDate: Int?)
  data class GoalEvent(
      val period: Int,
      val timeInPeriod: String,        // as the feed says it: "10:58"
      val isHome: Boolean,
      val scorer: String,              // "K. Marchenko"
      val goalsToDate: Int?,           // season goals as of this goal
      val assists: List<GoalAssist>,
      val strength: GoalStrength,
      val modifier: GoalModifier,
      val awayScore: Int?,             // score immediately after this goal
      val homeScore: Int?,
  )
  ```

  `GameLanding` gains `val goals: List<GoalEvent> = emptyList()`. A goal with no period number or no scorer name cannot
  be placed or attributed: drop that goal and keep the rest. A goal with an unrecognised `strength` keeps the event with
  `GoalStrength.Unknown` and renders no tag; do not drop it. Missing scores stay null rather than being invented.
- **`PeriodScoring` must not change.** It is built the way it is today; the new list is additive. If your change moves any
  period-table test or golden, stop and report instead of re-recording.

**B. The card.**

- Title `Scoring summary`, tag `detail.section.scoring`, loadable `detail.landing`, failure label
  `Scoring summary could not be loaded`, `hideWhenEmpty = { it.goals.isEmpty() }`.
- Position: **after the shots card and before Game stats** — the settled order is period table → shots → scoring summary
  → penalties → team stats → three stars → game info.
- Inside, grouped by period in ascending order, and within a period by `timeInPeriod` **descending** (newest first, the
  way a period is read when it ends). Each period gets a quiet header: `1ST`, `2ND`, `3RD`, and `OT` for the third extra
  period and beyond, sharing one `OT` group the way the tables share one column.
- One goal is two lines:
  - line 1: the time (`10:58`) in a fixed left column, then the scorer in the card's body weight, then the season count
    as `(12)` when `goalsToDate` is present, then a strength tag when there is one; then, right-aligned, the running score
    `2–1` from that goal's own away/home scores (en dash, away first).
  - line 2: the club abbreviation and the assists, in the muted label style — `CBJ · A: J. Voracek (4), Z. Werenski (9)`.
    With no assists say `CBJ · Unassisted`. Season counts appear only when `assistsToDate` is present.
- Strength tags: `PP`, `SH`, `EN`, `PS`. A goal can be both short-handed and empty-net; when both apply, print both in
  that order (`SH EN`). `EvenStrength` prints nothing.
- Every text stays at or above the 12 sp floor; the card must not print below it at font scale 2.0.
- Add tags for assertion: `detail.scoring.period.<n>`, `detail.scoring.goal.<eventIndex>` is **not** wanted — use one
  tag per goal row derived from its position (`detail.scoring.row.<zeroPaddedIndex>`), so a test can read a specific row.
